Everything, hands-free

Dictation, automation, and AI — a single tray app with no account and no cloud lock-in.

🎙️

Hold-to-talk dictation

Press and hold Ctrl + Shift + Space, start talking, let go. The transcript types itself into whatever is focused — email, chat, editor, terminal.

🧠

On-device Whisper

Transcription runs locally via a bundled whisper.cpp DLL. The default base.en model (~142 MB) downloads once on first run. Your audio never leaves the machine.

🗒️

Voice-triggered workflows

Say a trigger phrase and a whole multi-step workflow runs: draft, transform, insert, open apps, type, press keys. Matched by exact phrase, prefix, or regex.

⚙️

Composable steps

Six step types — prompt · shell · type · keys · open · wait — chained with {{output}} variables, each with its own timeout and error handling.

🔑

Your keys, always

Nothing is bundled or secretly contacted. Add an OpenAI-compatible key in Settings → AI (or set OPENAI_API_KEY) whenever you want AI steps.

🪟

Windows-native

System tray, global hotkeys, clipboard integration, single-instance guard. Config, logs and workflows live in %APPDATA%\aiop — plain, editable files.

How it works

No installer, no account. Four steps and you’re talking.

Download & run

Unzip anywhere and launch AIOP.exe. A tray icon appears and global hotkeys go live.

First-run model

One time, AIOP downloads ggml-base.en.bin (source huggingface.co/ggerganov) — then dictation is fully offline.

Add your AI key

Only for AI steps: open Settings → AI, paste a key, pick an endpoint and model (default gpt-4o-mini, any OpenAI-compatible URL works).

Record a workflow

Press Ctrl + Shift + W to open the editor, give a workflow a trigger phrase and steps, then just… say it.

Workflows are open, plain files

Every workflow is JSON at %APPDATA%\aiop\workflows\workflows.json — hand-edit it, version it, share it with anyone.

{
  "name": "Compose email",
  "enabled": true,
  "trigger": "compose email",
  "trigger_type": "prefix",
  "steps": [
    { "type": "prompt",
      "params": { "prompt": "Write a professional email about {{text}}. Sign it '- Your Name'." } },
    { "type": "type",
      "params": { "text": "{{output}}" } }
  ]
}

Saying “compose email, status update to the team” runs the prompt step with the spoken remainder as {{text}}, then the type step types the model’s reply with {{output}} into the focused window.

Privacy by design

Built for people who care where their speech and data go.

Speech stays on your machine

  • ✓ Transcription is 100% on-device Whisper — no audio or transcripts are uploaded.
  • ✓ No accounts, no telemetry, no usage reporting, no phone-home calls.
  • ✓ The only network I/O is (1) the one-time model download and (2) AI steps you enable.

AI steps are explicit and keyed by you

  • ✓ Only prompt steps send text — to the endpoint you configure, using your key.
  • ✓ Keys are stored locally, never logged, and never appear in error messages.
  • ✓ Point the base URL at Ollama, LM Studio, OpenRouter, or your own proxy.
  • ✓ Fully open source — audit every line.

FAQ

Do I need an OpenAI account or API key?

Only if you use prompt steps. Dictation, workflows, and all non-AI steps work offline with no key. When you do add one, it’s stored locally and sent only to your configured endpoint.

Can I use a free or local AI model?

Yes. Any OpenAI-compatible endpoint works — point base URL at e.g. http://localhost:11434/v1 for Ollama, or your LM Studio server, and any key/blank key it accepts.

Does AIOP upload my microphone audio?

No. Recording and transcription are local. Whisper models are downloaded once from Hugging Face; your audio is never sent anywhere.

Does it work fully offline?

Dictation and every step except prompt work offline. Prompt steps need to reach your AI endpoint.

How do I back up or share workflows?

Copy %APPDATA%\aiop\workflows\workflows.json. It’s plain JSON — paste it anywhere else with the same app.

Windows says it’s suspicious / SmartScreen blocks it

The app is packaged with PyInstaller and isn’t code-signed yet, which can trigger false positives. Build from source, check the SHA-256 of the release asset, or click “More info → Run anyway”.
