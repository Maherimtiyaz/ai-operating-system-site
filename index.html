Features

Everything, hands-free

Dictation, automation, and AI — one tray app with no account and no cloud lock-in.

🎙️

Hold-to-talk dictation

Press and hold Ctrl + Shift + Space, start talking, let go. The transcript types itself into whatever is focused — email, chat, editor, terminal. An on-screen status shows listening / working / done.

🧠

On-device Whisper

Transcription runs locally on a bundled whisper.cpp DLL. The default base.en model (~142 MB) downloads once on first run, then your audio never leaves the machine.

🗒️

Voice-triggered workflows

Speak a trigger phrase and a whole multi-step workflow runs — draft, transform, insert, open apps, type, press keys. Matched by exact phrase, prefix, or regex.

⚙️

Composable steps

Six step types — prompt · shell · type · keys · open · wait — chained with {{output}} variables, each with its own timeout and error handling.

🔑

Your keys, always

Nothing is bundled or secretly contacted. Add any OpenAI-compatible key in Settings → AI (or set OPENAI_API_KEY) only if you want AI steps.

🪟

Windows-native, open-format data

System tray, global hotkeys, clipboard integration, single-instance guard. Config, logs and workflows live in %APPDATA%\aiop as plain, editable JSON/YAML — version them, share them, build on them. Fully open source under Apache-2.0.

Setup guide

Get set up in 5 minutes

From zip to first voice command — every click covered.

1

Download & launch

Hit Download (top right or below). Unzip the folder anywhere — Desktop, Program Files, a USB stick — and double-click AIOP.exe. No installer, no admin rights. If SmartScreen asks, choose More info → Run anyway (the build isn’t code-signed yet). A tray icon appears in the taskbar and the hotkeys go live immediately.

2

First run — download the speech model once

On first launch the app opens the model picker. Keep base.en (~142 MB, English) for most use, or pick the multilingual base/small if you speak other languages. Click Download and wait — the progress bar persists across restarts. Afterwards, dictation is fully offline. You can switch models any time in Settings → Speech.

💡 Tip: want instant dictation while it downloads? Start with tiny.en and upgrade later.
3

Dictate right now

Focus any text field — Outlook, WhatsApp, VS Code, your terminal. Press and hold Ctrl + Shift + Space, start talking, and release when you’re done. The transcript formats itself into the focused window. Hold again to continue; keep talking in bursts for clean, fast completions.

4

Add your AI key (only for AI steps)

Right-click the tray icon → Settings → AI tab: paste your API key into the API key field. Keep Base URL https://api.openai.com/v1 and Model gpt-4o-mini — or point Base URL at any OpenAI-compatible endpoint (e.g. Ollama: http://localhost:11434/v1). Click Save. No restart needed. Prefer the terminal? Set OPENAI_API_KEY before launching. Keys are stored locally, never logged, and only ever sent to your configured endpoint.

5

Create your first workflow

Press Ctrl + Shift + W (or tray menu → Workflows…) to open the workflow editor. Give it a name, a trigger phrase like compose email, set Trigger type to prefix, add your steps (next section shows a full example), and press Save then enable it. Now just say it — the guided walkthrough below is a full end-to-end example.

First workflow

Your first voice workflow, end to end

“Compose email” — a real example you can recreate right now.

1 · Build it in the editor (Ctrl + Shift + W)

{
  "name": "Compose email",
  "enabled": true,
  "trigger": "compose email",
  "trigger_type": "prefix",
  "steps": [
    { "type": "prompt",
      "params": {
        "prompt": "Write a professional email about
                   {{text}}. Sign it '- Alex'."
      }
    },
    { "type": "type",
      "params": { "text": "{{output}}" }
    }
  ]
}

2 · Say it

Hold Ctrl+Shift+Space and speak:

“compose email, status update for the team”

AIOP matches the compose email prefix, sends the remaining text to your AI endpoint, then types the finished email into the focused window — with the status line about your team.

{{text}} {{output}}

{{text}} = whatever you spoke after the trigger. {{output}} = the previous step’s result (here, the model’s reply). Any step type can chain these.

📌 Prefix triggers are the sweet spot: one phrase, endless commands — only the remainder is passed to the prompt step.

Privacy

Privacy by design

Built for people who care where their speech and data go — everything is auditable source.

Speech stays on your machine

  • ✓ Transcription is 100% on-device Whisper — no audio or transcripts are uploaded.
  • ✓ No accounts, no telemetry, no usage reporting, no phone-home calls.
  • ✓ The only network I/O is the one-time model download and AI steps you enable.

AI steps are explicit and keyed by you

  • ✓ Only prompt steps send text — to the endpoint you configure, using your key.
  • ✓ Keys are stored locally, never logged, and never appear in error messages.
  • ✓ Point the base URL at Ollama, LM Studio, OpenRouter, or your own proxy.
  • ✓ Fully open source — audit every line.
FAQ

Questions, answered

Do I need an OpenAI account or API key?

Only if you use prompt steps. Dictation, workflows, and all non-AI steps work offline with no key. When you do add one, it’s stored locally and sent only to your configured endpoint.

Can I use a free or local AI model?

Yes. Any OpenAI-compatible endpoint works — point Base URL at e.g. http://localhost:11434/v1 for Ollama, or your LM Studio server, and any key it accepts.

Does AIOP upload my microphone audio?

No. Recording and transcription are local. Whisper models are downloaded once from Hugging Face; your audio is never sent anywhere.

Does it work fully offline?

Dictation and every step except prompt work offline. Prompt steps need to reach your AI endpoint.

How do I back up or share workflows?

Copy %APPDATA%\aiop\workflows\workflows.json. It’s plain JSON — paste it anywhere else with the same app.

How do I change dictation language or model?

Settings → Speech. The multilingual base / small models cover far more languages; larger models are slower but more accurate.

Windows says the exe is suspicious / SmartScreen blocks it

The app is packaged with PyInstaller and isn’t code-signed yet, which can trigger false positives. Build from source, check the SHA-256 of the release asset, or click “More info → Run anyway”.

Where are my config and logs?

Everything lives under %APPDATA%\aiop: config\config.yaml, logs\, models\, workflows\workflows.json.
